# ZAGA GAME — сайт VR-клуба

Одностраничный сайт. Работает на **GitHub Pages** (бесплатно).  
Фото добавляются через браузер — список обновляется сам (GitHub Actions).

---

## Как открыть сайт (GitHub Pages)

1. Открой репозиторий на GitHub.
2. Нажми **Settings** (вверху справа).
3. В левом меню выбери **Pages**.
4. В блоке **Build and deployment**:
   - **Source** → выбери **Deploy from a branch**
   - **Branch** → `main` (или `master`), папка **/ (root)**
   - Нажми **Save**
5. Подожди 1–2 минуты. Ссылка на сайт появится на этой же странице  
   (обычно `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`).

---

## Как добавить фото клуба (через браузер)

1. Открой папку **`assets/club`** в репозитории.
2. Нажми **Add file** → **Upload files**.
3. Перетащи фото с компьютера.
   - Главное фото на главном экране: назови файл **`hero.jpg`** (или `hero.png` / `hero.webp`).
   - Остальные фото — любые имена (покажутся в блоке Atmosphere, до 3 штук).
4. Внизу нажми **Commit changes**.
5. Подожди 30–60 секунд: GitHub Actions сам обновит список фото.
6. Обнови страницу сайта (Ctrl+F5) — новые фото появятся.

## Как добавить обложку игры

1. Открой папку **`assets/games`**.
2. **Add file** → **Upload files**.
3. Имя файла должно быть похоже на название игры  
   (например: `beat saber.png`, `gorn.png`, `arizona.jpg`).
4. **Commit changes** → Actions обновит список → обнови сайт.

## Как добавить новую игру (текст)

1. Открой файл **`js/games.js`**.
2. Нажми карандаш (Edit).
3. Скопируй один блок `{ ... }` и вставь ниже, поменяй название, описание и т.д.  
   Поле `image` оставь пустым: `image: ""`.
4. **Commit changes**.

---

## Проверка, что Actions работает

1. В репозитории открой вкладку **Actions**.
2. Должен быть workflow **«Auto update assets»**.
3. После загрузки фото появится зелёная галочка (успех) или красный крестик (ошибка).
4. Если красный — открой строку, посмотри лог. Чаще всего помогает повторный **Re-run**.

Можно запустить вручную: **Actions** → **Auto update assets** → **Run workflow**.

## Что править руками (без кода почти)

| Что | Файл |
|-----|------|
| Цены | `js/main.js` → массив `PRICES` |
| Вопросы FAQ | `js/main.js` → массив `FAQ_DATA` |
| Отзывы | `js/reviews.js` |
| Игры (названия, описания) | `js/games.js` |
| Телефон, адрес | `index.html` (поиск по `+375` или `Либкнехта`) |

## Передача сайта другому человеку

1. **Settings** → **Collaborators** → добавить его GitHub-аккаунт  
   **или**
2. **Settings** → **General** → внизу **Transfer ownership** — передать весь репозиторий.

После передачи покупатель включает Pages (см. выше) на своём аккаунте.  
Домен будет вида `https://его-ник.github.io/имя-репо/`.

---

## Ограничения GitHub Pages (бесплатно)

- Только статический сайт (HTML/CSS/JS) — у нас так и есть.
- Сайт публичный (его может открыть кто угодно по ссылке).
- Нет своего сервера и базы данных — всё хранится в файлах репозитория.
- Лимиты: обычно хватает с запасом для визитки (трафик, размер репо).
- Свой домен (например `zagagame.by`) можно подключить в **Settings → Pages → Custom domain**.

## Структура папок (кратко)

```
assets/club/     — фото клуба (hero.jpg = главное)
assets/games/    — обложки игр
js/games.js      — список игр
js/reviews.js    — отзывы
js/main.js       — цены, FAQ
js/generated/    — авто-список фото (не редактировать руками)
.github/workflows/ — автоматизация
```
