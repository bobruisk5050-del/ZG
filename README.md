# ZAGA GAME — сайт VR-клуба

## Как добавить фото клуба (через браузер)

1. Открыть папку **`assets/club`** в репозитории.
2. Нажать **Add file** → **Upload files**.
3. Перетащи фото с компьютера.
   - Главное фото на главном экране: назови файл **`hero.jpg`** (или `hero.png` / `hero.webp`).
   - Остальные фото — любые имена (покажутся в блоке Atmosphere, до 3 штук).
4. Внизу нажми **Commit changes**.
5. Подожди 30–60 секунд: GitHub Actions сам обновит список фото.
6. Обнови страницу сайта (Ctrl+F5) — новые фото появятся.

## Как добавить обложку игры

1. Открой папку **`assets/games`**.
2. **Add file** → **Upload files**.
3. Имя файла должно быть похоже на название игры  
   (например: `beat saber.png`, `gorn.png`, `arizona.jpg`).
4. **Commit changes** → Actions обновит список → обнови сайт.

## Как добавить новую игру (текст)

1. Открой файл **`js/games.js`**.
2. Нажми карандаш (Edit).
3. Скопируй один блок `{ ... }` и вставь ниже, поменяй название, описание и т.д.  
   Поле `image` оставь пустым: `image: ""`.
4. **Commit changes**.

## Что править

| Что | Файл |
|-----|------|
| Цены | `js/main.js` → массив `PRICES` |
| Вопросы FAQ | `js/main.js` → массив `FAQ_DATA` |
| Отзывы | `js/reviews.js` |
| Игры (названия, описания) | `js/games.js` |
| Телефон, адрес | `index.html` (поиск по `+375` или `Либкнехта`) |

## Структура папок (кратко)

```
assets/club/     — фото клуба (hero.jpg = главное)
assets/games/    — обложки игр
js/games.js      — список игр
js/reviews.js    — отзывы
js/main.js       — цены, FAQ
js/generated/    — авто-список фото (не редактировать руками)
.github/workflows/ — автоматизация
```
